## Cakupan audit yang dipertahankan

- Batas akun dan otorisasi: command, query, export, admin, sesi, dan validasi batas server dibaca; tes isolasi akun, tamu, serta admin dipertahankan. Tidak mengganti library login atau penerbitan Pro.
- Rumus: `packages/calc` tetap satu sumber HPP, margin, markup, harga jual, komisi, dan BEP. Tidak mengubah hasil PRD brownies.
- Produk kembali pakai: fitur simulasi dampak harga dan dashboard alarm sudah tersedia. Perbaikan membuat perubahan dari form bahan ikut masuk ke alur tersebut, tanpa membangun dashboard kedua.
- Deployment: membaca Docker, env, migrasi, webhook, backup, dan panduan yang sudah tersedia. Readiness hanya membuktikan koneksi DB, bukan keberhasilan Google OAuth, Mayar, atau backup restore produksi.
- Maintainability: menghapus duplikasi perhitungan laba di UI dan menyatukan jalur perubahan bahan. Tidak merombak folder atau menambah library.

## Verifikasi

- `pnpm.cmd test`: **109 lulus**, 20 berkas. Termasuk kasus PRD, isolasi akun, penyimpanan, webhook, schema, env, dan readiness.
- `pnpm.cmd typecheck` dan `pnpm.cmd lint`: **lulus** untuk perubahan final; lint memeriksa 242 berkas. `git diff --check` bersih.
- `pnpm.cmd build` dan `pnpm.cmd size`: build produksi berhasil; seluruh **35 manifest halaman** di bawah batas 220 KB JS / 300 KB total gzip. Public calculator sekitar **177,7 / 252,5 KB**; daftar resep sekitar **218,3 / 293,0 KB**. Ukuran ini ukuran aset build menurut script, bukan pengukuran Core Web Vitals atau latensi jaringan.
- `pnpm.cmd audit --prod --json`: **0 advisory** pada audit dependensi produksi saat sesi ini; bukan jaminan keamanan menyeluruh.
- Suite E2E lengkap dengan GA dimatikan: **183 lulus, 14 skip, 3 timeout** dari 200. Skip adalah 12 tes GA yang dijalankan terpisah serta 2 tes navigasi khusus desktop pada mobile. Timeout terjadi pada navigasi `/harga`, pembuatan tab browser, dan navigasi `/resep`; bukan kegagalan assertion produk.
- Pengulangan terarah setelah build Docker selesai, tanpa menaikkan timeout: **20/20 lulus**. Mencakup ketiga kasus timeout pada semua viewport/theme, J-1 brownies, dan validasi kalkulator publik. Suite lengkap tidak diklaim lulus dalam satu kali jalan.
- Suite analytics terpisah memakai `NEXT_PUBLIC_GA_ID=G-AUDITTEST01` dan mock script Google: **24/24 lulus**, termasuk dua skenario baru yang ditambahkan setelah suite lengkap dimulai. Tidak mengirim analytics sungguhan.
- `docker build --tag takaran-audit:local .`: **lulus**. Smoke test image dengan PostgreSQL 16 terisolasi: migrasi/startup berhasil, `/kalkulator-hpp` 200, `/api/health` 200 dan `Cache-Control: no-store`, status Docker healthy, lalu health 503 setelah DB dimatikan. Env token webhook kosong tidak menggagalkan startup. Kontainer dan jaringan uji sudah dibersihkan; image lokal tersisa untuk inspeksi.
- UI: axe, keyboard, overflow, dan screenshot diperiksa pada 320/1280 px dengan preferensi terang/gelap. Screenshot memperlihatkan fokus, hasil rupiah, fallback teks terpilih, dan logo footer dengan rasio yang benar. Share sheet/clipboard diuji lewat mock kemampuan browser, bukan pengiriman pesan nyata ke WhatsApp.

## Tindak lanjut operasional

1. Setelah deploy domain final, verifikasi Search Console, kirim sitemap, dan pantau kueri serta penggunaan kalkulator. Tidak ada jaminan peringkat atau kenaikan traffic.
2. Di properti GA4, matikan Enhanced Measurement sesuai CHANGE-004/005; pastikan ID build benar. Event klik masuk mengukur minat, bukan signup selesai. Analytics area akun tetap di luar keputusan yang disetujui.
3. Jalankan OAuth, Mayar, backup/restore, dan load test di staging dengan konfigurasi produksi sebelum rilis. Share berupa gambar atau link hasil tersimpan belum diperlukan karena share teks dan URL halaman sudah memenuhi kebutuhan tanpa penyimpanan data baru.
