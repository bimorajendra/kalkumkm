Data resep saya disimpan di mana?

Demo ini menghitung langsung di browser dan tidak mengirim angka resep ke server. Aplikasi Takaran dirancang menyimpan data resep di perangkatmu.

Kalau ganti HP, datanya hilang?

Di aplikasi Takaran, kamu bisa mencadangkan dan memulihkan data lewat satu file.

Apa bedanya margin dan markup?

Markup membandingkan untung dengan modal. Margin membandingkan untung dengan harga jual. Harga jual dihitung dengan HPP dibagi (1 dikurangi target margin).
